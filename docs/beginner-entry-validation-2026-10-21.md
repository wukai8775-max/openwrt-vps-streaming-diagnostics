可复现的离线验证命令：

```sh
python3 -m unittest discover -s tests -v
sh -n tools/snapshot.sh
sh -n tools/sample.sh
python3 tools/check-publication.py
git diff --check
```

`check-publication.py` 检查 Git 暂存区，发布前须先暂存准备公开的文件。自动检查只能覆盖常见泄露模式，仍需人工核对。公开报告只保留白名单指标及分类，不发布真实地址、网络标识、凭据、原始错误或配置。

## 尚未验证

本轮没有进行公网固定文件吞吐、路由器/VPS 两端测量、指定节点归属、真实手机直播、持续负载、晚高峰或并发验收。Windows 原生命令行及接口绑定尚未在独立环境验证。macOS 的一次轻量检查和本地 HTTPS 成功都不支持最高带宽或线路已修复的结论。

GitHub Actions 会在发布后对 Python 3.10 和 3.13 执行仓库离线检查；具体远端结果以该提交关联的 [工作流记录](https://github.com/wukai8775-max/openwrt-vps-streaming-diagnostics/actions/workflows/ci.yml) 为准。

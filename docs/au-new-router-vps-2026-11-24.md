# 2026-11-24 新路由器与澳洲 VPS：配置和待验收

本记录是北京时间当时的观察，不是实时状态。目标为一台锐捷 RG-X60 PRO V1.00，现场已运行 ImmortalWrt；本轮不据此推断刷写过程或固件来源。新路由器、旧生产网络和其他澳洲线路的结果分别记录。

## 配置与已观察到的状态

- 新路由器的 5 GHz 无线界面显示八个加密且可见的接入点，采用 WPA2-PSK；这些接入点接入同一 LAN，**不是八条独立出口，也未验证客户端相互隔离**。
- 新澳洲 VPS 的 Shadowsocks 服务已安装并设为开机启动；服务状态及 TCP/UDP 监听当时显示正常。路由器 PassWall 配置使用该节点，TCP、UDP 默认模式为全局代理，状态页显示 TCP、UDP 和 DNS 运行中。
- 防火墙界面显示 LAN 区域允许到 WAN 的转发、WAN 入站拒绝，未在所查看的规则中发现直接阻止 LAN 出站的自定义规则。这不是全链路防火墙审计，也未证明代理失效时不会直连或 IPv6 不会泄漏。
- 路由器到 VPS 的一次 ICMP 测试：20 个探测包，丢包 0%，平均约 230 ms。此结果不代表应用请求延迟、持续稳定性或可用带宽。
- 后续无线界面观察到一台设备关联其中一个新接入点并显示局域网地址；这不等于已验证互联网访问或代理出口。

## 故障与待完成事项

1. 一次将管理电脑切换到新 Wi-Fi 的尝试使远程控制中断；管理网络后来恢复。以后先保留独立管理路径，再用另一台设备验证，避免因切换控制网络而失联。
2. 路由器另有两个默认无线网络，当时显示未加密。用户要求设置密码；截至这份记录，未完成密码输入及应用，**不能视为已加密**。完成后重新读取无线状态并验证实际连接。
3. VPS 本机查询到其公网 IPv4，但尚未通过连接新接入点的客户端验证出口；地理定位结果可有数据库差异。需要实测 IPv4、IPv6、DNS 和代理异常时的行为，再确认符合出口要求。
4. 尚未完成客户端实际下载、上传、长时间稳定性、晚高峰、并发和直播测试。界面显示的无线链路速率、代理运行状态或短时 ping 都不能代替这些验收。
5. 测试前记录当前配置及恢复方法；不直接对正在使用的网络做全局防火墙、路由或无线重启修改。每次变更后确认管理连接、客户端取地址、DNS、网页和出口，出现异常先恢复。

具体网络名称、地址、设备标识、密码、代理凭据和完整配置不放入公开仓库；按 [公开边界](../SECURITY.md) 留在私有位置。
